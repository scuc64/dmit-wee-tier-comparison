## WEE 在 DMIT 的命名体系里是什么位置

DMIT 的套餐名是三段拼出来的：机房 + 线路 + 配置档。

机房是 LAX（洛杉矶）、HKG（香港）、TYO（东京），偶尔也有 SJC（圣何塞）。线路分三种：**Tier 1**、**Eyeball**、**Premium**。配置档按从小到大排是 WEE、TINY、STARTER、MINI、MICRO、MEDIUM、LARGE、GIANT。

所以“DMIT WEE”指的不是某一款机器，而是每条产品线里门槛最低的那一台。你搜到的 $36.9/年，可能是洛杉矶的 T1.WEE，也可能是香港或东京的 T1.WEE，价格一样，线路和回程完全不同。

三条线路的差别，官网购买页的原话大致是：

- **Tier 1**：优化欧亚之间、亚洲内部的国际互联路由，**不做**中国大陆方向优化
- **Eyeball**：在 Tier 1 基础上，对中国大陆路由做“尽力优化”（通常走 CMI 一类的运营商网络）
- **Premium**：在 Tier 1 基础上叠加 CN2 GIA 这类优质中转

“尽力”和“保证”这两个词在 DMIT 的说明里是分开写的，不是修辞。T1 的国际互联是硬指标，回国体验则看运气；EB 会想办法，但官方不承诺；Pro 才是明码标价的回国优化。这点直接影响你怎么选 WEE。

## T1 和 EB 的 WEE，差的这 3 美元值不值

先说 T1。有第三方测评记录测过 HKG.T1.WEE 的国内 TCP ping：移动平均 52ms（上海 29ms 到拉萨 98ms），联通平均 197ms，**电信平均 783ms**，最差节点在新疆乌鲁木齐，2226ms。这个数据把 T1 的定位说得很清楚——它压根没打算让大陆三网都好用。移动方向能看，电信方向基本躺平。

再看 LAX.EB.WEE。它的路由是：去程电信、联通走 CN2，移动走 CMIN2；回程三网统一走 CMIN2。CMIN2 是中国移动国际的下一代国际通道，带宽资源比普通 CMI 宽裕，绕行更少。社区里管这类机器叫“移动快乐机”，说的就是移动用户回程体验明显好于普通国际线路。

所以选择逻辑不复杂：

- 你的访客和业务主要在境外，或者你只是需要一个干净的国际出口 → T1.WEE，省下那 3 美元
- 你本地是移动宽带，且在意访问这台机器时的延迟和晚高峰稳定性 → EB.WEE 有货就上
- 你本地是电信宽带，又指望回国速度 → 这两款都不该选，WEE 之后应该直接看 Pro 系列，那不是 36.9 美元能解决的事

顺带一句，EB.WEE 属于限量款，售罄和下架是常态，历史上还出现过“Eyeball 系列暂时下线”的状态。T1.WEE 的补货频率明显更高。

## 超量之后“不限流量”到底限成什么样

DMIT 的流量政策是：跑完套餐内的高速流量后不停机，降到指定速率继续用，也就是所谓的“限速不限量”。

- 洛杉矶 T1 系列：降到 100Mbps
- 香港、东京 T1 系列：降到 50Mbps

换算一下，50Mbps 理论下载约 6.25MB/s，100Mbps 约 12.5MB/s。这个速度跑网页、SSH、同步小文件、看 1080p 视频都够用，但拿来做持续的大流量转发会很痛苦。反过来说，如果你一个月稳定只用几百 GB，这个降速条款基本不会触发，它更像是给突发流量兜底，而不是给你当无限流量套餐用。

> 注意：WEE 在部分页面标注的是单向计算流量，另一些页面写双向。这个细节差异会直接影响你的实际可用量，下单前在购物车页面确认清楚。

## WEE 适合谁，不适合谁

适合的场景比较集中：国际业务落地、跨区域数据同步、开发测试环境、监控探针、自用的小型代理出口、只对境外访客服务的轻量站点。这些用途的共同点是对回国线路不敏感，而对价格和端口带宽敏感——WEE 恰好是这两头都给得比较足的一款。

不该指望它做的事：

- **面向大陆访客建站**。T1 的回国路由没有优化，电信方向的数据就在那里摆着
- **流媒体解锁**。T1 定位国际互联，IP 质量不是卖点；有这类需求要么自测要么换线路
- **大流量转发**。超量降到 50Mbps 之后，这条路就走到头了

还有一条官方自己写明的提示值得留意：洛杉矶 **AS3 平台仍处于持续优化阶段，磁盘性能和 SLA 可能低于成熟平台**，介意的话建议先测试再部署重要业务。AS3 用的是 AMD EPYC 7003 系列，更成熟的平台是 AN4（EPYC 9004 系）和 AN5（EPYC 9005，官方叫 Next Platform）。同一款 WEE 在不同代次平台上硬件不一样，价格也可能不一样。

## 下单前值得确认的几件事

**付款方式**：支付宝、微信（通过 Stripe 或类似通道）、PayPal、信用卡都可选，部分渠道也接受 USDT。对国内用户来说支付宝直接付款是省事的地方。

**换 IP**：DMIT 的政策是每 15 天可免费更换一次被封锁的 IP，这在同价位商家里算宽松。具体次数和条件以官网服务条款为准。

**退款**：官方 TOS 里有独立的 Refund Policy 条款，社区记录的规则是 3 天内全额退款、30 天内按比例退款。这类条款随时可能调整，付款前自己翻一遍。

**平台代次**：购物车里同一个机房会同时出现 AS3 / AN4 / AN5 三个选项，价格和硬盘配置都不同。别默认点第一个。

## 几个被问得最多的问题

**WEE 和 TINY 差多少？**
差价不在性能上。T1.WEE 是 1核 1G 20G，年付 36.9 美元；T1.TINY 是 1核 1G 20G 但流量翻倍到 2000GB，月付 6.9 美元，折成年付反而更贵。TINY 的意义在于月付灵活、能吃到优惠码，WEE 的意义在于一次性把年费压到最低。

**WEE 能建站吗？**
能，前提是你的访客不在大陆，或者你不介意电信访客的体验。1GB 内存跑 Nginx + 数据库的小站没什么压力，但并发量上不去。

**为什么 WEE 总是缺货？**
它是补货型的特价款，不是常规在售品。每次上架量有限，通常几天内售完。想买的话盯紧补货通知，或者直接看购物车里的库存状态。

**T1 和 EB 到底怎么选？**
看你的本地网络和业务方向。移动宽带 + 在意回国体验选 EB；纯国际用途、在意端口和价格选 T1。两者都不做中国大陆路由保证，这不属于“买错了”的范畴，属于产品定位。

**WEE 那 3 美元差价里还有别的区别吗？**
有。EB.WEE 的端口是 1Gbps，T1.WEE 是 4Gbps；EB 的回程走 CMIN2，T1 走国际互联。选 EB 买的是线路，选 T1 买的是带宽和低价。
